# Marketing Generated Content Visibility Audit

**Updated:** 2026-05-20 (post-PR-#14 stabilisation)

## Contract
- Generated content must be visible immediately.
- Generated content must survive refresh and be queryable later.
- Pack outputs must persist and appear in content library lists.
- A bad/malformed content row must NEVER crash the list.
- Rejection must be a safe state transition, not a crash path.

## Implemented API Paths
- `GET /api/v1/content/items`
- `GET /api/v1/content/items/{id}`
- `GET /api/v1/content/webapp/{webapp_id}`
- `DELETE /api/v1/content/items/{id}?confirm=true`
- `POST /api/v1/content/items/{id}/reject` ← NEW
- `POST /api/v1/content/items/{id}/schedule`
- `POST /api/v1/content/items/{id}/duplicate`
- `POST /api/v1/content/items/{id}/improve`
- `GET /api/v1/content/provenance` ← NEW
- `POST /api/v1/content/items/{id}/review-grounding` ← NEW

## Content Lifecycle Status Flow

```
PENDING → APPROVED → SCHEDULED → POSTED
PENDING → REJECTED (kept, filterable, feeds learning)
PENDING → DELETED (hard delete via /items/{id}?confirm=true)
any → IMPROVED (new item created, parent_item_id in metadata)
any → DUPLICATED (new item created, duplicated_from in metadata)
```

## Resilience Fixes (post-PR-#14)

- `list_content_items`: each row serialized in try/except — bad row returns safe stub, never 500
- `_content_item_payload()`: all field accesses use safe defaults (`_safe_str`, `_safe_list`, hasattr guards)
- Dashboard boot: each API call isolated (readiness, content, library each have own try/catch)
- AuthProvider: only clears session on 401/403, NOT on 500/network errors

## UI Paths Using Persisted Data
- `/dashboard/content` (Content Studio + Content Library)
- `/dashboard/businesses/:id` (business-specific drafts, pack/media metadata, quick actions)
- `/dashboard` (recent generated items and media job counts)

## Content Library UI Improvements
- Default filter: `active` (hides rejected/deleted from default view)
- Rejected items visible under "Rejected" filter with red badge
- Provenance info on each card: business name, source action, generated by
- Rejection dialog with optional feedback field
