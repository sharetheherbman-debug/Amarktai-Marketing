# MARKETING CONTENT PROVENANCE AUDIT

**Date:** 2026-05-20  
**Repo:** sharetheherbman-debug/Amarktai-Marketing  

---

## Problem

Content items appeared in the library with no traceable origin.  
It was impossible to tell: who generated it, which business triggered it, which
route created it, or whether it was real or smoke-test data.

---

## Fields Added to Every Content Item

| Field | Type | Source |
|---|---|---|
| `id` | string | auto UUID |
| `user_id` | string | auth token |
| `webapp_id` | string | request param |
| `business_name` | string | webapp.name at generation time |
| `source_route` | string | hardcoded per endpoint |
| `source_action` | string | hardcoded per endpoint |
| `campaign_id` | string? | optional campaign context |
| `generated_by` | string | provider_actual |
| `provider_attempted` | string | first provider tried |
| `provider_actual` | string | provider that succeeded |
| `model_actual` | string | model used |
| `task_used` | string | generation task |
| `capability_used` | string | format capability |
| `source_business_snapshot` | json | full business context at generation time |
| `status` | string | draft/approved/rejected/scheduled/deleted/failed |
| `rejection_reason` | string? | from reject endpoint |
| `created_at` | datetime | DB server default |
| `updated_at` | datetime | DB on update |

---

## New Endpoint

`GET /api/v1/content/provenance`

Filters:
- `webapp_id`
- `source_action`
- `status`
- `provider`
- `date`

Returns a compact provenance record for each matching item including:
`id`, `webapp_id`, `business_name`, `platform`, `status`,
`source_route`, `source_action`, `generated_by`, `provider_actual`,
`model_actual`, `rejection_reason`, `created_at`.
